# First-Day Operations Plan — Build 12.0.0

## Monitoring intervals

- Before opening
- At opening
- 30 minutes after opening
- Lunch ramp
- Lunch peak
- Mid-afternoon reset
- Dinner ramp
- Dinner peak
- Quick EOD
- Inventory close
- Final daily review

## At each interval

Review service health, authentication failures, API errors, database connections, critical workflow latency, Today exceptions, load status, EOD readiness, inventory holds/exceptions, reporting reconciliation, and open incidents.

Record the reviewer, timestamp, result, evidence, and follow-up owner.
