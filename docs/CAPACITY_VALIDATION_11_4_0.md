# Smoker Capacity Validation — Build 11.4.0

## Approved baseline

- Ole Hickory EL-ED/X: 80 pork butts or 40 briskets.
- Southern Pride SPK-700: 84 pork butts or 48 briskets.

## Still requiring measured approval

- Ribs on each PTT smoker.
- Chicken whole-bird-equivalent double breasts on each PTT smoker.
- Mixed-load equivalency.
- Rack spacing and airflow limitations.
- Maximum safe load under actual operating conditions.
- Recovery time and performance across repeated cycles.

## Validation protocol

1. Record smoker brand, model, asset ID, location and cook window.
2. Load a measured quantity using actual racks and product geometry.
3. Confirm airflow, rotation clearance, temperature recovery and food-safety performance.
4. Record raw weight, unit count, start/end times, finished quality and yield.
5. Repeat enough cycles to establish a defensible operating maximum.
6. Approve capacity with actor, date, evidence and effective date.
7. Preserve old capacity versions for historical plans.

Values marked `validationOnlyCapacities` are test inputs only and cannot support production approval.
