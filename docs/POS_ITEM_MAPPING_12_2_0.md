# POS Item Mapping — Build 12.2.0

Mappings are tenant-, location-, and provider-scoped. Each mapping retains provider item identity, target category, optional PTT product, cooked-pound conversion, version, effective date, and status.

Supported targets include BRISKET, PORK, RIBS, CHICKEN, BAR, MERCHANDISE, OTHER_FOOD, and IGNORED.

Unmapped lines are quarantined. They remain visible in reconciliation but are excluded from forecast learning. Configuration from another location cannot be substituted.
