# Location Onboarding and Deactivation — Build 12.1.0

## Activation controls

Identity, timezone, service hours, products, smokers, users, forecast profile, inventory policy, opening inventory, and training must all pass. Only ADMIN or OWNER can activate.

## Deactivation blockers

- Open operating day
- Open transfer
- Active quality hold
- Unreconciled inventory
- Unresolved P0/P1 defect

Deactivation blocks new operations but retains historical records and reporting.
